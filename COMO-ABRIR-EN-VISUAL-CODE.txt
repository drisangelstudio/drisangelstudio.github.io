CÓMO ABRIR EN VISUAL STUDIO CODE (COMPUTADORA)
1. Descomprimí el ZIP.
2. VS Code → Archivo → Abrir carpeta → ANGEL-DRIS-PORTFOLIO-EMAIL-URUGUAY-LIMPIO.
3. Abrí index.html con Live Server o ejecutá desde la terminal en esta carpeta:
   python3 -m http.server 8000
4. En tu navegador entrá a http://localhost:8000/

EN GITHUB CODESPACES (IPAD)
1. Cargá el ZIP en el Explorador de VS Code (clic largo en la carpeta → «Cargar…»).
2. En la terminal, dentro de la carpeta a la que se subió el ZIP, ejecutá:
   unzip -o ANGEL-DRIS-PORTFOLIO-EMAIL-URUGUAY-LIMPIO.zip
3. Entrá a la carpeta con:
   cd ANGEL-DRIS-PORTFOLIO-EMAIL-URUGUAY-LIMPIO
4. Iniciá el servidor:
   python3 -m http.server 8000
5. En el aviso del puerto 8000, tocá «Abrir en el navegador».
NOTA: si ya hay un servidor activo en el puerto 8000, detenelo con Ctrl+C o usá 8001.
